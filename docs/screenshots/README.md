# Capturas

Imágenes que usa el README principal. Hazlas en **modo demo**, para que no salgan títulos ni textos de tus chats reales. La demo está toda en inglés. Desde la carpeta del proyecto:

```bash
pkill -f Claudio.app; open build/Claudio.app --args --demo
```

En modo demo, el menú del icono tiene **«Pet state (demo)»** para ponerla en reposo, pensando, trabajando, terminado, te necesita o dormida.

Al terminar, `pkill -f Claudio.app; open build/Claudio.app` la vuelve a abrir normal.

## Cómo hacerlas
- **Una ventana o un menú, con sombra:** ⇧⌘4, luego pulsa la barra espaciadora y haz clic en la ventana.
- **Una zona (mascota y globito):** ⇧⌘4 y arrastra.
- **Vídeo:** ⇧⌘5 → «Grabar parte seleccionada».

Mejor con un fondo de escritorio sencillo, en PNG y en una pantalla Retina, para que se vean nítidas.
