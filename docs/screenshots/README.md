# Capturas

Imágenes que usa el README principal. Hazlas en **modo demo**, para que no salgan títulos ni textos de tus chats reales. Desde la carpeta del proyecto:

```bash
pkill -f Claudio.app; open build/Claudio.app --args --demo
```

En modo demo, el menú del icono tiene **«Estado de la mascota (demo)»** para ponerla en reposo, pensando, trabajando, terminado, te necesita o dormida.

Al terminar, `pkill -f Claudio.app; open build/Claudio.app` la vuelve a abrir normal.

| Fichero | Qué tiene que salir |
|---|---|
| `mascota-globito.png` | La mascota en el escritorio con el globito de "Rediseño de la página de inicio" y sus dos opciones |
| `menu-uso.png` | El menú al hacer clic en el icono, con las barras de uso (42 % y 76 %, esta en naranja) |
| `chats.png` | El desplegable al pasar el ratón por el icono, con la lista de chats |
| `ajustes.png` | La ventana de Ajustes |
| `notificacion.png` | Una notificación, desde Ajustes → «Probar aviso» |
| `estados.gif` (opcional) | Vídeo corto de la mascota pasando por los estados |

## Cómo hacerlas
- **Una ventana o un menú, con sombra:** ⇧⌘4, luego pulsa la barra espaciadora y haz clic en la ventana.
- **Una zona (mascota y globito):** ⇧⌘4 y arrastra.
- **Vídeo:** ⇧⌘5 → «Grabar parte seleccionada».

Mejor con un fondo de escritorio sencillo, en PNG y en una pantalla Retina, para que se vean nítidas.
